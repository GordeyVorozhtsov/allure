GitLab

Люди входят через Keycloak. Джоба не входит туда: в CI кладётся токен проекта, zip уходит заголовком X-API-Token.

curl -F files=@results.zip \
  -F execution_name=gitlab \
  -F execution_url="$CI_PIPELINE_URL" \
  -F execution_type=gitlab \
  -F execution_branch="$CI_COMMIT_REF_NAME" \
  -H "X-API-Token: $ALLURE_TOKEN" \
  https://allure.local/projects/checkout/results
